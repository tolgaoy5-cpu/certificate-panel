Certificate Reader

An internal Excel panel for the property certificate tracker. Open the property certificate tracker, click Home → Add Certificates, and drop certificate PDFs or photos onto the panel.

Each file is read, matched to a property on the Properties sheet and added to the Certificates sheet. Anything uncertain is shown in the panel for a quick check first. Save the workbook when you're done.

Documents are sent only to the Claude API to be read. Nothing is stored on this website.
